# Лабараторная работа №6

---

## 1. Статистика (`statistics.py`)
Программа запрашивает у пользователя строку целых чисел через пробел, вычисляет и выводит количество элементов, сумму, минимум, максимум и среднее арифметическое (с двумя знаками после запятой). При пустом вводе выводится «Нет данных», функции `min()` и `max()` не вызываются, деление на ноль исключено.

### Проверки:
* Ввод: `-2 0 5 3`
  * Вывод: 
    ```
    4
    6
    -2
    5
    1.50
    ```
* Ввод: `8`
  * Вывод: 
    ```
    1
    8
    8
    8
    8.00
    ```
* Пустой ввод: выдает сообщение `Нет данных`.

---

## 2. Преобразование (`transform.py`)
Программа создает новый список, заменяя все отрицательные числа их модулями, при этом исходный список сохраняется в неизменном виде.

### Проверки:
* Ввод: `-2 0 5 -2`
  * Вывод:
    ```
    [-2, 0, 5, -2]
    [2, 0, 5, 2]
    ```

---

## 3. Позиции (`positions.py`)
Программа находит все индексы максимального элемента в списке в порядке возрастания с использованием обхода через `enumerate()`. Для пустого списка выводится «Нет данных».

### Проверки:
* Ввод: `7 7`
  * Вывод: `[0, 1]`
* Ввод: `-3 -1 -2`
  * Вывод: `[1]`

---

## 4. Вариант 6 (`variant.py`)
* **Условие:** Числа, кратные 3.
* Программа выбирает из введенной строки числа по заданному условию, выводит их в исходном порядке, а также считает их количество, сумму и формирует новую отсортированную по возрастанию копию.

### Проверки:
* Ввод: `-8 -3 0 6 6 1`
  * Вывод:
    ```
    [-3, 0, 6, 6]
    4
    9
    [-3, 0, 6, 6]
    ```
