# Лабораторная работа: Коллекции в Python

## Описание работы
Данная лабораторная работа посвящена изучению базовых коллекций в Python: спискам (`list`), словарям (`dict`), множествам (`set`) и кортежам (`tuple`).

## Выбор структур данных
1. **Словарь (`dict`)** 
   - Используется для задачи подсчёта частоты слов (`word_counts`), а также для агрегации сумм в функции `totals_by_category`. 
   - Словарь удобен, так как позволяет связывать уникальный ключ (слово или категорию) со значением (количеством или суммой порций).
   - Метод `.get(key, default)` применяется для безопасного обращения к элементам словаря: если ключ отсутствует, возвращается значение по умолчанию (`0`), что предотвращает ошибку `KeyError`.

2. **Множества (`set`)** 
   - Используются в функциях `common_topics` и `all_topics` для работы со списками учебных интересов.
   - Множества автоматически удаляют дубликаты и предоставляют удобные операции: пересечение (`&`) и объединение (`|`).
   - Использование `sorted()` перед выводом необходимо, так как множества не гарантируют порядок элементов, а по условию задачи результат должен быть воспроизводимым.

3. **Кортежи (`tuple`)** 
   - Кортеж применяется для хранения неизменяемой пары элементов (например, названия блюда и порций или слова и его частоты).
   - Поддерживает удобный механизм распаковки переменной (`name, count = pair`).
