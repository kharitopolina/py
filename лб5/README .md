# Лабараторная работа №5
---

### 1. Нормализация текста (`normalize.py`)


* **Пример 1:**
  * **Ввод:** ` Один  два `
  * **Вывод:** 
    ```text
    Исходная длина: 10
    Новая длина: 8
    Нормализованный текст: Один два
    Количество слов: 2
    ```
* **Пример 2 (пустая строка):**
  * **Вывод:** длина `0`, слов `0`.

---

### 2. Проверка на палиндром (`palidrome.py`)

* **Пример 1:** `А роза упала на лапу Азора` → `Палиндром`
* **Пример 2:** `а ` → `Палиндром`
* **Пример 3:** Строка из пробелов → `Нет текста`
* **Пример 4:** `Python` → `Не палиндром`
* **Пример 5:** `А!` → `Не палиндром` (по принятым правилам).

---

### 3. Замена символов (`replace.py`)


* **Пример 1:** 
  * **Ввод:** `a::b:`
  * **Вывод:** `a--b-`, замен `3`.
* **Пример 2:** 
  * **Ввод:** `abc`
  * **Вывод:** без изменений, замен `0`.

---

### 4. Обработка слов по вариантам (`variant.py`)


* **Пример с текстом:** `Анна, армия! Я читаю.`
  * **Вариант 1 (начинается с `а`):** `анна`, `армия`, количество `2`.
  * **Вариант 2 (заканчивается на `я`):** `армия`, `я`, количество `2`.
  * **Вариант 3 (длина не меньше 5):** `армия`, `читаю`, количество `2`.
  * **Вариант 6 (длина равна 4):** `анна`, `край`, `рама`, количество `3`.
* **Дополнительные проверки:** 
  * Пустой ввод / строка `!!!` → `Нет совпадений`, количество `0`.
