## 1. Сравнение базовх выражений (Прогноз/Python)

| Выражение | Ручной прогноз | Результат Python | Совпадение |
| :--- | :---: | :---: | :---: |
| `2 + 3 * 4` | **14** | **14** | Да |
| `(2 + 3) * 4` | **20** | **20** | Да |
| `17 // 5` | **3** | **3** | Да |
| `17 % 5` | **2** | **2** | Да |
| `-7 // 2` | **-4** | **-4** | Да |

```python
print("2 + 3 * 4 =", 2 + 3 * 4)     # Вывод: 14
print("(2 + 3) * 4 =", (2 + 3) * 4) # Вывод: 20
print("17 // 5 =", 17 // 5)         # Вывод: 3
print("17 % 5 =", 17 % 5)           # Вывод: 2
print("-7 // 2 =", -7 // 2)         # Вывод: -4
```

### `time_parts.py`

* **Тестовый прогноз (для `3665` сек):**
  1. `hours` = $3665 \mathbin{/\!/} 3600 = 1$ ч.
  2. Остаток после часов = $3665 \bmod 3600 = 65$ сек.
  3. `minutes` = $65 \mathbin{/\!/} 60 = 1$ мин.
  4. `seconds` = $3665 \bmod 60 = 5$ с.
* **Результат работы Python:** `1 ч 1 мин 5 с` *(Прогноз совпал)*.

###  `variant.py`

* **Тестовый прогноз:**
  * **Тест 1 (`total = 23`, `capacity = 5`):**
    * `full_units` = $23 \mathbin{/\!/} 5 = 4$
    * `remainder` = $23 \bmod 5 = 3$
    * `total_units` = $((23 + 5 - 1) \mathbin{/\!/} 5) \times \text{bool}(23) = (27 \mathbin{/\!/} 5) \times 1 = 5$
    * **Прогноз вывода:** `4`, `3`, `5`
  * **Тест 2 (`total = 0`, `capacity = 5`):**
    * `total_units` = $((0 + 5 - 1) \mathbin{/\!/} 5) \times \text{bool}(0) = 0$
    * **Прогноз вывода:** `0`, `0`, `0`
* **Результат работы Python:** Вывод полностью совпадает с прогнозами для всех случаев.
