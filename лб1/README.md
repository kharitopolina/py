# Пример расчета заказа (Вариант 6: Цветочный магазин)

## Исходные данные:
- **Заказ:** Цветочный магазин
- **Заказчик:** Полина
- **Товар 1:** Розы (количество: 3, цена: 12.50 руб.)
- **Товар 2:** Тюльпаны (количество: 2, цена: 20.00 руб.)
- **Доставка:** 10.00 руб.
- **Внесённая сумма:** 100.00 руб.

## Ручной расчёт:
1. **Стоимость товара 1:** 3 * 12.50 = 37.50 руб.
2. **Стоимость товара 2:** 2 * 20.00 = 40.00 руб.
3. **Общее количество единиц:** 3 + 2 = 5 шт.
4. **Стоимость товаров без доставки:** 37.50 + 40.00 = 77.50 руб.
5. **Общая сумма с доставкой:** 77.50 + 10.00 = 87.50 руб.
6. **Сдача:** 100.00 - 87.50 = 12.50 руб.
