## Реализованные функции (`table.py`)

1. **`row_sums(matrix)`**
   * Возвращает список сумм элементов каждой строки.
   * Для пустой матрицы `[]` возвращает `[]`.

2. **`column_sums(matrix)`**
   * Возвращает список сумм элементов каждого столбца.
   * Учитывает прямоугольную форму матрицы (количество строк и столбцов может не совпадать).

3. **`diagonal_pattern(size)`**
   * Генерирует квадратную матрицу размера $size \times size$:
     * На главной диагонали (`row == column`): `0`
     * Выше главной диагонали (`row < column`): `1`
     * Ниже главной диагонали (`row > column`): `2`

4. **`transform(matrix)` — Вариант 6**
   * Заменяет все нулевые элементы матрицы на `1`.
   * Возвращает новую матрицу той же формы, не меняя исходную.

## Защита и контрольные вопросы

### 1. Какую ошибку выявляет таблица $2 \times 3$?
Прямоугольная матрица размера $2 \times 3$ (где количество строк не равно количеству столбцов) выявляет ошибку предположения о квадратной форме матрицы. Если алгоритм суммирования столбцов опирается на количество строк вместо длины строки `len(matrix[0])`, возникнет либо ошибка выходя за пределы индекса `IndexError`, либо неверный подсчёт элементов.

### 2. Почему нельзя повторять одну изменяемую строку?
При создании матрицы конструкцией вида `[[0] * columns] * rows` происходит копирование **ссылки** на один и тот же список в памяти. 
В результате все строки таблицы становятся одной и той же связной строкой: изменение элемента в одной ячейке (например, `matrix[0][0] = 7`) приведет к изменению первого элемента во всех остальных строках одновременно.

### 3. Чем копия внешнего списка отличается от копирования строк?
* **Копирование внешнего списка** (например, `matrix.copy()`) создаёт поверхностную копию (shallow copy). Копируется только сам внешний список, но его элементами остаются ссылки на те же самые внутренние списки строк. Изменение элементов внутри строк всё ещё затронет исходную матрицу.
* **Копирование строк** (поэлементное или через `[row.copy() for row in matrix]`) создаёт глубокую независимую копию (deep copy). В этом случае внутренние списки строк создаются заново, и любые изменения в новой матрице никак не влияют на оригинал.
